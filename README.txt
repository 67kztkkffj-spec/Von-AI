VON AI free frontend preview

This ZIP contains the mobile web interface only. It can be hosted on GitHub Pages for free.
The AI chat and transcription features require a separately configured secure backend.
Never place an API key in these public files.

From an iPhone:
1. Create a GitHub repository and upload the CONTENTS of the public folder to the repository root.
2. In repository Settings > Pages, select Deploy from a branch, main, / (root).
3. Visit the Pages URL after deployment.
4. In Safari, Share > Add to Home Screen.
